# Aenderungen in dieser Version

Diese Version enthaelt die zuletzt gewuenschten Kassensystem-Erweiterungen:

1. Anmeldung beim App-Start
   - Die Kasse startet mit einer Benutzeranmeldung.
   - Benutzer koennen mit oder ohne Passwort betrieben werden.
   - In der Verkaufsmaske ist kein Benutzerwechsel mehr moeglich.
   - Stattdessen gibt es eine Logout-Taste.

2. Benutzer & Rechte
   - Im Adminbereich koennen Benutzer angelegt, aktiviert/deaktiviert und mit
     Rechten versehen werden.
   - Passwort/PIN und Passwortpflicht sind pro Benutzer einstellbar.

3. Produktverwaltung
   - Neue Produkte koennen hinzugefuegt werden.
   - Bereits vorhandene/importierte Produkte koennen geaendert werden.
   - Angepasste Standardprodukte koennen wieder zurueckgesetzt werden.
   - Anzeigeort und Unterkacheln sind beim Produkt waehlbar.

4. Zahlungen
   - Gutschein-Teilzahlung wird unterstuetzt.
   - Der Restbetrag laeuft automatisch auf Bar.
   - Kartenzahlung wird nicht angeboten.

5. Adminbereich
   - Uebersichtliches Menue: Produkte, Rabatte, Benutzer & Bons.
   - Rabattvorlagen koennen gepflegt werden.
   - Adminbereich ist passwortgeschuetzt.

6. Bons und Druck
   - Bonlayout kann angepasst werden.
   - Bonrollenbreite 57 mm oder 80 mm ist waehlbar.
   - Fiktiver TSE-Stempel wird auf Wunsch gedruckt.
   - Bluetooth-Druckvorbereitung fuer kompatible Drucker ist enthalten.

7. Tablet/Handy-App
   - App erkennt Geraeteart und Darstellungsmodus.
   - PWA-Dateien fuer Installation auf Tablet oder Handy sind enthalten.

## Wichtig

Diese Version ist technisch vorbereitet, aber noch kein rechtssicheres
produktives Kassensystem. Fuer echten Betrieb muessen echte TSE-Anbindung,
Datensicherung, Benutzer-/Passwortkonzept und Drucker-Hardware final geprueft
werden.
